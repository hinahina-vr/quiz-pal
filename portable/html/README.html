QUIZ PAL · LOCAL HTML

展開して、HTMLを開くだけ。

Windows・Mac・Linux向けの、ローカルHTML形式です。アプリ用のEXE、Node.js、コマンド入力、ローカルサーバーは使いません。

Quiz Pal を開く →

はじめ方

  1. ZIPをすべて展開します。Windowsは「すべて展開」、MacはZIPをダブルクリック、Linuxはアーカイブマネージャーで展開します。
  2. 展開した Quiz-Pal-HTML フォルダーの index.html を、通常のブラウザウィンドウで開きます。HTMLがエディターで開く場合は「アプリケーションで開く」からブラウザを選びます。
  3. 紹介の後に使い方ガイドが始まります。教材管理・クイズ・利用条件は、画面内のリンクで移動できます。

フォルダーごと保管してください。
HTMLのほかに、JavaScript・CSS・教材・画像・フォントが同梱されています。index.html だけを取り出すと動きません。

保存と引っ越し

教材・履歴・設定・画像は、使っているブラウザの中に保存します。HTMLやZIPそのものには書き込みません。同じフォルダー、同じブラウザ、同じブラウザプロファイルで開いてください。

フォルダーを移動・改名する前、アプリを更新する前、別のブラウザやPCへ移る前は「セーブ」を押してください。移動先で「ロード」を押し、保存したJSONファイルを選ぶと復元できます。従来のWindows版・Web版からも、セーブ／ロードで移せます。

ブラウザデータの削除やプライベートウィンドウの終了で、記録が消える場合があります。定期的にセーブしたファイルを保管してください。APIキーはバックアップに含めません。

ネット接続とAI

問題を解く、教材を作る・直す、CSVを読み込む、セーブ／ロードする基本機能はオフラインで使えます。AIへの質問・AIでの問題作成・モデル一覧の取得にはネット接続が必要です。有料モデルには、ご自身のAPIキーとAPI側の利用枠を用意してください。

AIへの通信はブラウザから利用先APIへ直接送ります。API側がローカルファイルからの接続を許可していない場合は利用できません。ブラウザのセキュリティ設定を無効にする必要はありません。

開けないとき

  • ZIP内から直接開かず、すべて展開してから index.html を開いてください。
  • Chrome・Edge・Firefoxなど、保存機能が利用できるブラウザの通常ウィンドウを使ってください。ブラウザごとにローカルHTMLの保存制限が異なります。
  • 新しいフォルダーで以前の記録が見えない場合は、以前の保存場所でセーブし、新しい場所でロードしてください。

OS・ブラウザ別の実機確認範囲は、配布時の検証記録を参照してください。HTML形式であることだけをもって、すべてのブラウザで確認済みとはしていません。
